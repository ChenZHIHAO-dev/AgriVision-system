每个作物的 `sources` 保存原始发布包、原图、来源与许可元数据；`review` 保存审核决定；`prepared` 保存唯一工作图和清单；`evaluation` 保存外部来源的评估清单。实验引用同一批照片，输出放 `artifacts/experiments/<任务>/<方法>/fold-N`，不复制出 dataset01/02。

小麦 `reference` 仍被筛选表引用，不能作为无用副本删除；`archive` 是已有历史结果，不参与当前训练。下一次改数据时先停止读取它的实验，更新同一筛选表，再明确替换同一 `prepared`。训练中的清单、图片和代码保持冻结。

统计分清四个量：原包文件数、精确去重图数、入选工作图数、独立观察/近重复组数。增强视图不算新增真实样本；近重复组数也不等于已确认独立植株数。

### 病名与未覆盖类别

- `Yellow/Stripe Rust` 对应条锈，`Brown/Leaf Rust` 对应叶锈，`Black/Stem Rust` 对应秆锈，三者不能混成一个标签。
- `Scab/Fusarium Head Blight` 对应赤霉，当前主要拍麦穗；`Glume Blotch` 保留原始颖枯标签。泛称 `Leaf Blight/Septoria/Smut` 必须回查原来源、病原和器官，不能仅按相似英文合并。
- 健康参考表示来源标注健康、未发现本模型覆盖病害的明显特征，不证明照片中不存在其他病害。
- 黄斑叶枯、秆锈、散黑穗仍缺通过质量核验的工作图；茎基腐、纹枯、根腐、麦蚜和麦蜘蛛保留资料条目，当前不输出对应预测。没有真实图片的类别不生成空标签或虚构 other 样本。

[黄斑原始田间研究](https://doi.org/10.1016/j.compag.2017.04.013)、[WFD](https://wfd.sysbio.ru/index.html)、[PlantSeg](https://zenodo.org/records/17719108)作为补图线索。WFD 需申请；PlantSeg 当前只取得许可元数据和部分索引，未将未到手原图计入训练。

## 人工筛选与标签对应

图片文件名是稳定哈希或源照片 ID，**不是类别编码**。标签来自 CSV 同行的 `label`，图片由 `path` 关联，`source`、`raw_labels`、`note` 和来源表用于追溯。小麦筛选 path 相对 `data/wheat/review`；最终训练 manifest 的 path 相对各自 `prepared/images`。外测清单使用自己的 data-root 约定，不混用。

Excel 编辑保存 CSV UTF-8。`decision=keep` 表示入选、`drop` 表示排除、空值待筛，备注写原因。来源未授权、病名冲突、数字水印/拼图、非目标寄主、严重遮挡留待处理。接受来源标签的开关只用于内部基线，不能覆盖已有人工 drop、hold 或物种冲突。

## 预处理、增强与评估分开

1. **离线预处理**：Pillow 解码、EXIF 方向校正、RGB、长边最多 1024（不放大小图）、JPEG 质量 92；保存工作图。去重/合并已知采集关系后按组划分，记录逐图分辨率和来源。原比例不同是正常的，不在这里强拉方形。
2. **训练时在线增强**：`augmentation.py` 每次读取在内存中处理；不保存一份份增强图片。当前 CV 使用 light：水平翻转、±10° 旋转，亮度/对比度 ±12%、饱和度 ±10%。field 是另一个实验配置，增加 ±3% 平移、0.95–1.05 缩放；15% 概率选一种退化：3×3 模糊 σ=0.1–0.7、JPEG 75–95 或高斯噪声 σ=3/255。不是这三种全部叠加。
3. **模型输入**：当前方案等比缩放补边（letterbox）到 Swin-T 224×224 或 ConvNeXt-Tiny 320×320，再按 ImageNet 均值/方差归一化；验证和推理使用相同确定性规则，没有训练随机扰动。尺寸/缩放规则随 metadata 一起部署，老模型可能保留历史 stretch 规则。
4. **类别平衡**：当前 CV 用类别损失权重，默认为 `N/(K×n_class)`；幂次可调，不同时默认叠加过采样。平方根采样是另一种可对照方法：每类抽取总量约与 `sqrt(n_class)` 成正比，降低多数类优势，同时比强行等量重复少数图更温和。它目前不是默认执行方式。
5. **评估**：开发数据分五折，内层验证用于早停、超参数与校准，外层用于方案比较；原最终测试排除在开发折之外。同原图/观察/确认近重复组不跨折。五折主要评估稳定性，不会凭空提高某个单模型的能力，也不默认部署五模型集成。

这些增强参数是轻量、保留病斑特征的实验起点，不是论文证明对本数据最优的常数。比较方案看同一划分的 Macro-F1、逐类召回、错例、置信度和外部来源；增强不增加真实病种/地区覆盖。不同模型容量和数据偏差需要实测区分。[类别平衡损失](https://arxiv.org/abs/1901.05555) · [解耦表示与分类器](https://arxiv.org/abs/1910.09217) · [跨分布评估 WILDS](https://proceedings.mlr.press/v139/koh21a.html)

## 地区信息、知识库与后续补缺

地区、时间、生育期是用户选填信息，用于回答的适用性、观察建议和资料检索；不填也能识别和回答。不凭地区硬删除图像候选，不把发布单位所在地自动当采集地点。官方遥感分布和农业报道用于知识与采样规划，不能当病害图像训练集。

病害 ID 连接图像输出与知识卡。资料卡可逐步补，缺资料时明确覆盖不足，不拿其他病种的卡片作依据。知识条目保留规范名、别名、部位、混淆项、适用条件、出处和更新时间；具体建议随用户提供的信息和可核验资料变化。
