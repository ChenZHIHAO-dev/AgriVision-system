# 全国小麦病虫害数据与预处理

更新于 2026-11-25。国内 V2 是可复现的实拍基线。本轮整理小麦叶片与麦穗，先确认照片与标签质量，再进行数据增强和模型选型。

## 人工筛选

打开 `data/wheat/review/photos/` 查看按中文候选名归档的 Kaggle 图片。`标签冲突待核` 中同一张图片有多个原始类别，泛标签也保留待核。`data/wheat/review/review.csv` 汇总这些候选与国内基线的已有照片。国内照片通过 `../reference/images/` 路径引用。表中的 `path` 相对 `data/wheat/review/`。

| 可填写字段 | 填法 |
| --- | --- |
| `decision` | 通过填 `keep`，淘汰填 `drop`，待确认留空。国内基线照片和通过类别映射及文件检查的 Kaggle 照片已预填 `keep`，可按原图更正。 |
| `label` | 保留或更正已有规范 ID。对空标签先核对原图和原标，辨不清就留待确认。 |
| `note` | 记录更正理由、待细分的病名或查到的出处。 |

`source`、`raw_labels` 和 `review_reason` 帮助核对，`path` 和 `sha256` 用于识别原图片。另可查 `provenance.csv` 的原始成员路径、原划分和来源说明，以及 `summary.json` 的计数。确认国内基线照片与新增候选后，按[运行数据预处理](recognition-training-checklist.md#运行数据预处理)生成工作图、混合清单和分辨率统计。独立的国内田间图继续用于外测。

搜索找到的照片也可作为候选。记录原始发布页、摄影出处和使用范围，拍摄地点不详时保留未知。确认标签后按同一个规范 ID 和现有图片查重。论文、网盘链接和搜索结果中的缩略图等到获取可核对的原图后再计数。

## 叶片筛选和文件名

早期叶片专用筛选使用 `data/wheat/review/leaf-review.csv`，共 **8,435 张候选**。主体是条锈病、叶锈病、白粉病、黄矮病和健康麦叶。黄斑叶枯病也列出 712 张候选待确认，抽查发现其中夹有非小麦图。国内健康参考只选原 YOLO 标注为 `Wheat Leaf` 的 424 张，Kaggle 的 `Healthy` 还需按器官核对。该版本先筛叶片，麦蚜、蝇类、其他虫害和以穗、根、茎为主的类别留待后续。 [郑州市农业农村局的黄斑叶枯病资料](https://zzny.zhengzhou.gov.cn/nysc/6245185.jhtml)

`data/wheat/review/photos/` 的 11,143 张均从 Kaggle v6 包整理，国内照片由筛选表引用 `data/wheat/reference/images/`。Kaggle 的长文件名是用原始文件内容算出的 SHA-256。筛选表的 `path` 指向图片，同行的 `label` 是类别 ID。要查 Kaggle 原始文件名和原标签，用文件名里的 SHA-256 在 `provenance.csv` 中查找。国内照片的原标注路径在 `data/wheat/reference/sources.csv`。

一张实拍图里有多片麦叶时，只要症状清楚就可以保留。不同视角拼在一张图里时，训练缩放后各子图中的病斑会更小，分隔线和文字也会成为模型可见的画面特征。遇到这类图可在表里将 `decision` 填 `drop`，用 `note` 记录原因。 [本机筛选命令](recognition-training-checklist.md#先看要处理几套数据)

## 国内版类别怎么筛

以国内发生证据、照片的标注精度和实际优先度确定输出类别。Kaggle 的拍摄地可以是国外或未知。若病虫害在国内有可靠发生记录，图像确认后可作为混合训练候选。下表为字节去重后的候选目录数量。实际选入范围见[当前混合清单](#当前混合清单)。

| 先怎么处理 | 类别与筛选依据 |
| --- | --- |
| 保留现有六病和健康参考 | 国内基线已有条锈、叶锈、白粉、赤霉、颖枯、黄矮、健康参考。Kaggle 可先筛条锈 1,351、叶锈 1,212、白粉 1,131、赤霉 645、健康 1,036。颖枯和黄矮在 Kaggle 没有确认可直接映射的目录。 |

## 目录怎么放

- `data/wheat/sources/china-wheat/<来源名>/` 存放原始发布 ZIP 和 `source.json`。一来源一目录，原包内的图和标注保持原样。`source.json` 记录来源、版本、地区、许可和校验值。
- `data/wheat/prepared/` 是当前叶片与麦穗的质量优先工作集。
- `data/wheat/archive/mixed/` 是早期 11 类混合结果，留作对照和接口检查。
- `data/wheat/review/` 是人工筛选入口。当前使用 `leaf-spike-review.csv`，Kaggle 去重候选按类别放在 `photos/`。
- `data/wheat/reference/` 为筛选表提供河南、陕西图片及原分组。计划留作跨区外测的原图放独立目录。

先从河南原阳资料开始。保留每张图与同名标注的关系，按本页的类别表核原图。陕西资料单独复核并确认产品用途。主要缺口是茎基腐病、纹枯病、麦蚜、麦蜘蛛和跨产区的独立手机实拍。

## 预处理与增强实验

### 先清洗和划分原图

按 `review.csv` 确认病类和可用范围，用 `sources.csv` 或 `provenance.csv` 回查容易混淆的照片。先做跨库精确和近重复检查，再按田块、采集批次、植株和重复组分配训练、验证、测试。同株连拍及局部裁图跟随原图。保留症状仍清楚的阴影、轻微失焦和不同拍摄角度。验证和测试只做确定性的模型输入处理，另外保留独立国内手机图做田测。 [PlantVillage 同叶分组方法](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2016.01419/full) · [跨分布评测 WILDS](https://proceedings.mlr.press/v139/koh21a.html)

### 图像尺寸和输入格式

| 环节 | 当前做法和用途 |
| --- | --- |
| 原始资料归档 | 保留下载原图、真实格式和来源。用解码器识别 JPEG、PNG 或 WebP 等内容，统一 EXIF 方向和 RGB 后再制作工作图。按可见症状筛图，短边低于模型输入尺寸先标记复查，放大后原有细节仍有限。 |
| 国内 V2 工作图 | 校正 EXIF，保持长宽比，长边最多 1,024 像素，保存为质量 92 的 RGB JPEG。这一层统一管理数据，原图保持可回查。当前包可用于不同输入尺寸的对照。 [国内导入代码](../ml/agrivision_ml/prepare_wheat_cn.py) |
| 手机上传与服务保存 | 服务按实际内容接收 JPEG、PNG、WebP，上传上限 8 MiB，解码上限 2,400 万像素，短边不足 160 会产生画质提示。校正 EXIF 后，当前服务保比例压到长边最多 2,400，保存为质量 90 的 RGB JPEG。体积和解码限制用于上传与内存管理。 [后端图像处理](../services/api/app/imaging.py) |
| 模型读取 | JPEG 等是文件格式。模型收到的是三通道浮点张量。当前默认把整张图拉伸到 224×224，用双线性插值，再做 ImageNet 均值与标准差归一化。训练额外使用随机增强。现在模型包记录 `resize=stretch`，推理按包读取 `input_size`，尚未按 `resize` 切换几何规则。API 会做 EXIF 校正，命令行直接读原图目前只转 RGB。 [共享预处理](../ml/agrivision_ml/model.py) · [推理入口](../ml/agrivision_ml/inference.py) |

实际读取了全部图像头。国内 V2 的 5,566 张工作图短边中位数 768，只有 4 张短边低于 288。Kaggle 的 11,143 张待审图短边中位数 256，有 3,592 张低于 224、7,149 张低于 288，996 张的长边超过短边 2 倍。这个差异说明应先检查有效病斑和虫体像素，再决定如何缩放。特别窄的原图和过小的截图可优先复核。

| 图像几何方式 | 用 1,200×900 横图做 224 输入 | 取舍 |
| --- | --- | --- |
| 双轴拉伸 | 直接到 224×224 | 全图可见，原来圆形的病斑可能变成椭圆。当前模型使用这一版，适合复现基线。 |
| 等比缩放后补边 | 内容 224×168，上下各补 28 像素 | 全图和形状都保留，病斑用到的像素减少。边宽可能暴露来源，国内黄矮样本恰好都来自同一来源且为 672×448。验证时按来源、宽高比和病类检查。 |
| 等比放大至短边再中心裁剪 | 先约 299×224，再取中间 224×224 | 主体居中时细节占输入更多，横向合计裁掉约四分之一，边缘症状可能消失。随机裁剪增强也需要可见病部或已有框的约束。 |

**项目对照顺序**用同一划分，先比较 224 拉伸与 224 等比补边。确定几何方式后，若国内独立验证图上的小病斑有明显细节损失，再比较 224 与 288。288 的输入像素约为 224 的 1.65 倍，在目标 CPU 实测包括解码在内的单张延迟和每类召回。对细小且不在正中间的症状，优先试补近照或利用已有框保留病部周围的上下文。MobileNetV4 Conv-S 论文给出 224 的基准设置。EfficientNet 研究比较分辨率与计算量的折中。FixRes 说明裁剪和输入尺寸会改变病斑一类目标在模型里呈现的尺度，论文结果用于设计对照。 [MobileNetV4 · ECCV 2024](https://arxiv.org/html/2404.10518) · [EfficientNet · ICML 2019](https://proceedings.mlr.press/v97/tan19a.html) · [FixRes · NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/hash/d03a857a23b5285736c4d55e0bb067c8-Abstract.html) · [小麦手机拍摄研究](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2020.558126/full)

后续选定新的输入方式时，将 EXIF 方向、输入尺寸、拉伸或补边方式、插值、填充值和归一化写入模型配置，让训练、验证、阈值校准、API 和命令行调用共享。旧 224 拉伸权重按原配置加载。

### 把每轮读图次数拉近

自然采样时，有 400 张与 100 张的两类，每类平均出现次数之比是 4∶1。完全均衡会把这个比例压到 1∶1，使小类同一批原图反复出现。平方根采样把每张图的权重设为 `1 / sqrt(本类图数)`。400 张大类总权重是 20，100 张小类总权重是 10，类别出现次数约变成 2∶1。它调的是模型看到各类的频率，特别小的类别仍需要新的田间照片。按类加权损失则保持读图频率，只调整每次预测错误对更新的影响。

原图继续保留。按**筛选、去重、划分完成后的训练集**统计每类真实图数量。第一组对照沿用当前自然抽样加类频率加权损失。另一组用平缓的平方根采样，每张图权重取 `1 / sqrt(该类训练图数)`，每轮总抽样次数保持一致，损失使用统一类权重。真实图区分组重复使用时只产生新的视角，原图和田块数量分别报告。某类只有很少的独立田块时优先补采，限制单一采集组的抽样比重。 [ICLR 2020 长尾识别采样](https://arxiv.org/abs/1910.09217) · [CVPR 2019 有效样本数](https://arxiv.org/abs/1901.05555)

### 加噪起点与验证

| 处理 | 首轮对照的起点 |
| --- | --- |
| 轻几何与曝光 | 沿用水平翻转概率 50%、旋转 ±10°、亮度和对比度 ±12%、饱和度 ±10%。色相保持原样，检查锈疱、白粉和黄叶颜色。裁剪前确认仍保留症状和必要的整株背景。 |
| 高斯噪声 | 像素转成 0–1、进入 ImageNet 归一化前，加均值为 0、标准差 2–5/255 的噪声，结果裁到 0–1。在 8 位像素里相当于标准差 2–5 个灰度级。每张从范围内抽一个强度。 |
| 其他手机退化 | 轻度失焦可试高斯模糊 σ 0.3–0.8 个输入像素，转发压缩可试 JPEG 质量 80–95。虫体或病斑一处理就辨不清时减弱幅度。 |
| 应用比例 | 起步约 10%–15% 读图额外加一种模拟退化，噪声、模糊和压缩互斥，其余沿用轻量基线。要单测加噪收益，先做同采样、同基础增强、有无高斯噪声的对照。 |

上述数值是工程试验起点。手机实拍的噪声与设备和曝光有关。小麦手机研究使用了多设备、多角度和光照的实拍，田间叶片论文也比较过几何增强。ImageNet-C 提供模拟噪声、失焦和压缩的压力测试思路。建议用真实低光、压缩和轻微失焦照片核对模拟外观，抽看病斑和虫体细节后定幅度。 [手机条锈研究](https://www.frontiersin.org/journals/plant-science/articles/10.3389/fpls.2020.558126/full) · [田间小麦增强实验](https://www.mdpi.com/2072-4292/14/14/3446) · [手机噪声实测 CVPR 2018](https://openaccess.thecvf.com/content_cvpr_2018/html/Abdelhamed_A_High-Quality_Denoising_CVPR_2018_paper.html) · [ImageNet-C ICLR 2019](https://arxiv.org/abs/1903.12261)

**怎样确定参数。** ±10° 等是现有代码的基础增强幅度。保留它作为对照，可以单独看其他改动的影响。10%–15% 表示 100 次读取里约 10–15 次做额外退化，既能观察鲁棒性，也让大多数训练输入仍接近真实原图。2–5/255 是 8 位 RGB 通道的 2–5 格标准差。举例，像素值是 100、标准差取 3 时，约 95% 的同类扰动在 94–106 之间，靠近通道上下限时再截断。ImageNet-C 原实现里一级高斯噪声约是 20.4 格，用于压力测试。这里用更轻的范围起步，目的是优先保住小病斑纹理。这些值是项目拟试设置，论文提供选择退化种类和做对照的方法。

拿到目标手机真图后，在日光、阴影和低光下各拍几组同一静止表面的近似平坦区域，保持对焦和曝光可比，避开纹理边缘。把两张对齐的照片按模型输入尺寸缩放。若噪声近似独立且幅度相近，可用像素差的标准差除以 √2 估一张图的噪声幅度。拟合前先看模拟画面能否保住病斑颜色和轮廓。用相同划分分别对照无额外退化、10% 轻噪声，再决定是否比较 15% 或单独的模糊与压缩。选择依据是独立田间验证集的逐类召回、Macro-F1 与清晰图误判，测试集留到定稿。 [手机 sRGB 噪声 · CVPR 2022](https://openaccess.thecvf.com/content/CVPR2022/html/Kousha_Modeling_sRGB_Camera_Noise_With_Normalizing_Flows_CVPR_2022_paper.html) · [ImageNet-C 原实现](https://raw.githubusercontent.com/hendrycks/robustness/master/ImageNet-C/imagenet_c/imagenet_c/corruptions.py)

固定数据划分、模型与训练轮数。对照当前采样、平方根采样、平方根采样加轻退化，先看国内独立验证集的 Macro-F1、逐类召回和混淆，以及未知症状误接受率。合成退化图可以作为一组单独测试，最终测试集留到方案确定后再使用。小麦研究发现温室背景可能替代病斑提供判定线索，少数类补采时优先增加独立田块和真实拍摄条件。 [小麦田间与温室背景实验](https://bsppjournals.onlinelibrary.wiley.com/doi/full/10.1111/ppa.13684)

## 拍照和选地区怎么安排

1. **相机允许直接拍。** 确认作物为小麦后即可拍摄。可选填叶、穗、茎基/根或虫体，拍完后也能补。典型条锈或白粉有可见细节时可给图像候选。上传一张白穗或黄叶时，应补拍症状近照、整株和茎基，必要时继续核对生育期与田间分布。
2. **地区放在结果页选填。** 当用户要看当地资料、候选接近或需要区分生育期时，提示补充省和市县，可跳过。位置以用户选择为准，有需要再提供主动定位。地区只存到足够匹配资料的行政区。后台保留省市县、麦区、播种季、生育期以及信息来源，省份内部可能跨麦区。
3. **V2 首版让图像分数独立。** 识别依据是画质、可见部位、图像分类及校准分数。地区与季节用于挑选下一张该拍哪里、检索当地报告和解释当季风险。保留少见但图像吻合的候选。地区性预报和实际检出分别展示。资料按县市当季、省级当季、全国分区和全国通用鉴别依次检索，显示发布机构、日期和适用范围。 [全国农技中心分区通知](https://www.agri.cn/sc/zxjc/zwbch/202604/t20260428_8832031.htm) · [宁夏实地监测](https://nynct.nx.gov.cn/xwzx/zwdt/202606/t20260601_5252192.html)
4. **以后用数据检验地区是否值得参与排序。** 用同一批跨地块、年份和麦区留出图，对比纯图像与图像加地区/生育期。单独报告罕见类召回、未知误接受和未填地区时的表现。两省的公开训练包不足以估计全国病类流行先验，不能把数据集里的类比例直接当各省发病率。

## 数据准备好后怎么选模型

| 实际拿到的条件 | 后续选型 |
| --- | --- |
| 主要是图级单标签近照；每个试做类有几百张独立原图，并有多个地块或来源 | 优先用现有 **ImageNet 预训练 MobileNetV4-Conv-Small** 与 **EfficientNet-B0** 在同一清单比较。起点使用 224，分别统计小虫、早期病斑和跨麦区召回。出现细节丢失再比局部补拍与较高输入分辨率。这里的几百张是采集量级，选择依实际可用样本与分组。 [MobileNetV4 · ECCV 2024](https://www.ecva.net/papers/eccv_2024/papers_ECCV/html/5647_ECCV_2024_paper.php) · [EfficientNet · ICML 2019](https://proceedings.mlr.press/v97/tan19a.html) |
| 某类只来自一个地点或少量重复照片 | 该类先留在知识库或返回不确定，继续补采。数据小而标签可靠时，可用冻结 DINOv2 ViT-S 特征加轻量分类头做离线对照。是否上线看跨区收益和目标 CPU 耗时。 [DINOv2](https://arxiv.org/abs/2304.07193) |
| 具备足量、经复核的病斑/虫体方框；确有小目标或定位需求 | 优先单独做麦蚜、麦蜘蛛或麦穗定位的轻量检测支路，例如 RTMDet-tiny。报告小目标召回和在手机实际上传图上的表现。只有可靠的共现标注时，才试图级多标签。 [RTMDet 原文](https://arxiv.org/abs/2212.07784) |

初版保持一个小麦图像分类入口。按叶、穗、茎基/根和虫体提示拍摄与补拍，先用相同标签协议收数据。是否拆分器官支路，按各部位可用样本和外测误判决定。最终在独立麦区/田块报告每类召回、Macro-F1、接受覆盖率、被接受准确率、未知误接受和目标 CPU 延迟。论文的实验成绩用于设计对照。跨分布的表现以项目自己的外测为准。 [跨分布评测 · WILDS](https://proceedings.mlr.press/v139/koh21a.html)
