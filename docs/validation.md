# 验收与历史报告

## 代码回归

日常运行 [前端、Python 和构建命令](development.md#测试和现场检查)。前端测试覆盖输入、导航、主题、资料与微信构建。Python 通过独立的应用工厂创建测试实例，覆盖账户隔离、识别、资料问答、模型和数据处理。测试目录中的 `__pycache__` 是 Python 字节码缓存。

## 2026-11-25 本机检查

- Vue 类型检查通过。测试目录调整后，58 项前端和 174 项 Python 回归通过。H5、Pages、微信源码和 App 资源构建通过。
- Chrome 检查桌面 1366×900、手机 390×844 和窄屏 320×680。已验证首页资料切换、游客登录提示、演示问答和深色拍照页。模拟键盘遮挡 230 px 时，输入栏贴合可见区，页面基准高度保持 680 px。
- 在临时 API 与账户上上传真实小麦图，验证模型回执、补拍提示、登录接续原图与资料解析。使用本机 CPU 模型及本地问答服务。

## 本机与真机核对

| 场景 | 检查动作 |
| --- | --- |
| 桌面与窄屏 H5 | 检查首页入口、三栏切换、照片选择、历史搜索和返回。验证桌面双列、手机单列及深浅色 |
| 微信和 App 真机 | 从首页进入拍照、对话和我的。检查相机权限、胶囊或状态栏、底部安全区、键盘打开与收回、多行输入、长结果窗口和退出 |
| API 和登录 | 游客上传照片，核对识别或补拍状态。点继续对话取消登录后回到原图，随后用测试账户登录接续，验证记录可见性 |
| 对话和资料 | 直接发问，核对必要信息补全与自动恢复原问题、回答后的参考提示、引用、复制和下一问 |
| 模型验收 | 查看数据报告、测试曲线和逐类结果。目标 CPU 上测耗时，标记独立田试的采集来源与边界 |

App 启动和相机、键盘、返回等交互需 Android 和 iOS 运行基座或安装包实测。微信预览流程见 [扫码测试](wechat-deployment.md#用手机微信扫码)。
