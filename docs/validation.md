# AgriVision 开发验证记录

## 1.1 前端验证补充（2026-11-17）

- 6 项前端状态回归通过：管理员凭据、注册校验与摘要存储、访客问诊和登录归档、账户记录隔离、用药资料规则、Pages 资源路径、系统主题监听与手动主题覆盖。其中访客归档与隔离在同一项测试中检查。

- 实际浏览器验证了访客咨询、错误密码、密码确认不一致、注册、admin 登录、退出、按需登录提示与记录隔离。
- 电脑 1280×720、手机 390×844 和较矮窗口 390×500 下，咨询输入区都在可视范围，文档没有整体纵向或横向溢出。消息区域单独滚动。
- 主题切换保留当前咨询；手机的图片选择、图片压缩保存和生育期原生选择已验证。图片使用项目自制插画，记录中注明不是病害样本。
