## 本机与真机核对

| 场景 | 检查动作 |
| --- | --- |
| 桌面与窄屏 H5 | 检查首页入口、三栏切换、照片选择、历史搜索和返回。验证桌面双列、手机单列及深浅色 |
| 微信和 App 真机 | 从首页进入拍照、对话和我的。检查相机权限、胶囊或状态栏、底部安全区、键盘打开与收回、多行输入、长结果窗口和退出 |
| API 和登录 | 游客入口先提示登录，取消后保留原页面；登录后上传照片，核对识别或补拍状态，再验证记录与图片只对本账户可见 |
| 对话和资料 | 直接发问或沿用已有照片追问；选填信息可跳过，核对回答后的参考提示、引用、复制和下一问 |
| 模型验收 | 查看数据报告、测试曲线和逐类结果。目标 CPU 上测耗时，标记独立田试的采集来源与边界 |

App 启动和相机、键盘、返回等交互需 Android 和 iOS 运行基座或安装包实测。微信预览流程见 [扫码测试](wechat-deployment.md#用手机微信扫码)。
