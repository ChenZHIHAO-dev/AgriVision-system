# AgriVision 1.1 前端完善与测试待办

本轮先完成前端和接口边界，不新增账户数据库。保留 1.0 的模型与后端代码；网页默认使用独立的本地演示适配层，GitHub Pages 不依赖本机服务。

## 访客与账户

- 访客可上传图片、查看资料说明、连续咨询和浏览知识。
- 打开历史记录时展示登录引导；无需登录也可以返回问诊。
- 测试账户为 `admin / admin123`；注册支持称呼、账号、密码、确认密码和重复账号校验。
- 账户信息、偏好和已登录用户的演示记录保存在当前设备。访客问诊只保留在当前页面内，登录后可归入当前测试账户。
- 本地注册不保存明文密码，使用加盐摘要匹配测试凭据。这仍是前端测试逻辑，不能充当正式身份认证或管理权限。
- 退出登录保留该账户在此设备的记录，其他测试账户无法通过演示接口读取它们。不提供跨设备同步。

## 布局与交互

顶栏、内容区和移动底部导航分开。工作台只滚动内容区，顶部始终可见当前页面、连接方式、主题入口和账户状态。

咨询使用独立布局：固定问诊工具栏、可滚动消息区、常驻输入区。手机进入咨询时收起底部导航；输入区参与布局，不覆盖消息。H5 根据 Visual Viewport 的尺寸变化调整可视高度，小程序预留键盘高度适配。

少量互斥项平铺选择；生育期和地区用系统原生选择控件；电脑弹窗居中、手机弹窗从底部展示。弹窗正文独立滚动，标题、关闭和主操作保持可见，支持 Esc、Tab 焦点约束与关闭后恢复焦点。删除记录需要二次确认。

主题为浅色、深色、跟随系统，默认跟随系统并监听变化。通过语义色变量分别配置背景、面板、弹层、正文、次要文字、边框和操作色。深色弹层比背景更亮，保持层次。

设计参考：[Apple Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode)、[Apple Color](https://developer.apple.com/design/human-interface-guidelines/color)。应用保留用户要求的三种外观选项。

## 接口边界

`src/lib/api.ts` 保留原有业务接口，`preview.ts` 提供同结构的本地实现。设置中可明确切换前端体验与后端连接。Pages 默认不访问 localhost，不存放 API 密钥，也不把演示回答描述为 DeepSeek 或病害识别结果。

`src/lib/auth.ts` 定义 `AuthGateway`，当前使用测试实现。后端开发时替换它，并在服务端执行认证、授权与记录归属检查。拟定接口如下，当前没有声称已经实现这些服务：

| 计划接口 | 请求 / 返回 | 状态 |
| --- | --- | --- |
| POST `/api/auth/login` | 账号、密码 → 用户与服务端会话 | 待后端实现 |
| POST `/api/auth/register` | 称呼、账号、密码 → 用户 | 待后端实现 |
| GET `/api/auth/me` | 服务端会话 → 当前用户 | 待后端实现 |
| POST `/api/auth/logout` | 撤销服务端会话 | 待后端实现 |
| 记录归属与访客迁移 | 服务端验证所有权，再迁移当前访客记录 | 待后端实现 |
| 密码找回与限流 | 短信 / 邮件通道、失败次数限制 | 待服务方案确定 |

正式接口返回统一错误结构与 401、403、409、422 状态；正式会话宜使用 HTTPS 与 HttpOnly Cookie，并核对 CSRF。当前前端测试登录不改变旧后端的访问权限。

## GitHub Pages

目标仓库为 [AgriVision-system](https://github.com/ChenZHIHAO-dev/AgriVision-system)，前端地址为 `https://chenzhihao-dev.github.io/AgriVision-system/`。

`npm run build:pages` 生成 `apps/client/dist/pages`，设置 `/AgriVision-system/` 基础路径并保留 hash 路由。GitHub Actions 在推送 main 后执行前端测试、类型检查、小程序编译与 Pages 构建，再部署网页。Pages 只托管静态前端；Python 推理和实际对话需要单独部署后端。

公开仓库适合当前不含内部资料的体验版。GitHub Free 的 Pages 支持公开仓库；私有仓库的 Pages 支持取决于账户方案，且不能把仓库私有视为网站访问控制。[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages)
