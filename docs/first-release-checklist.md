# 第一版功能与交互验收清单

更新：2026-11-17。本轮先完成业务逻辑与软件交互，不继续重训或调整模型阈值。新检查项全部通过后再记为完成，浏览器尺寸测试与真机测试分别记录。

## 1. 识别与咨询

- [x] 按逐张结果归纳，不让最后一张覆盖前面的线索。
- [x] 一致病害、部分未判明、健康参考混入、不同病害、画质失败、版本混杂分别处理，测试通过。
- [x] 独立识别不调用对话模型，测试通过。
- [x] 对话接收明确识别回执，不把未匹配标签说成未收到图片，测试通过。
- [ ] 使用真实图片和 DeepSeek 再验收新的整条链路。
- [ ] 可选联网默认关闭，Flash 开启时返回真实来源；Pro 不伪装支持联网。

## 2. 账户、记录与权限

- [ ] 访客当前会话只在服务器内存中暂存，不写问答历史或图片文件。
- [ ] 登录后按服务器账户身份保存记录；更换客户端会话标识仍能读取自己记录。
- [ ] 未登录内容不自动迁入账户，登录后开始保存后续问诊。
- [ ] 管理员配置由后端校验角色，普通用户看不到后端地址、模型接入和体验模式。
- [ ] 暂不建立账户数据库，使用开发账户适配器；正式数据库和部署接入另行记录，不冒充已完成云端上线。

## 3. 首页与拍照

- [ ] 首页只保留作物选择、拍照 / 上传入口、最近问诊和必要说明。
- [ ] 大卡片可点击，打开拍照 / 相册选项；相机按钮只触发拍照。
- [ ] 地区、生育期与品种移到咨询信息补充，不阻塞 CNN 识别。
- [ ] 明确本版已支持的作物，未接入作物不伪造识别结果。

## 4. 导航、我的与设置

- [ ] 底部为问诊、咨询、知识、外观、我的，移除重复的记录入口。
- [ ] 咨询历史在电脑侧栏和手机抽屉，访客显示登录引导。
- [ ] 右上角头像保留，进入用户中心；“我的”置于底部最右。
- [ ] 独立用户设置页与管理员控制台，避免一个弹窗塞入全部功能。
- [ ] 浅色 / 深色 / 跟随系统直接循环，图标及系统模式文字明确，设置页也保留主题选择。

## 5. 显示与弹层

- [ ] 下拉选项共用组件，电脑浮层、手机底部面板；关闭、键盘操作与嵌套弹窗层级正确。
- [x] Markdown 渲染和 HTML / 远程图片防护单测通过。
- [ ] 实际浏览器检查 Markdown 标题、粗体、列表、表格、代码和长链接。
- [ ] 浅色避免大面积纯白；深色检查正文、次级文字、图标、主按钮、边框、占位与禁用状态。

## 6. 手机、键盘与动画

- [ ] 登录 / 注册弹窗随可视窗口缩小，输入后按钮可见，内容区能独立滚动。
- [ ] 聊天输入区常驻；底部导航仅在键盘弹出时平滑收起，收起后恢复。
- [ ] 轻量位移与透明度动画，支持减少动态效果。
- [ ] 实际 iOS / Android 软键盘及微信真机另行验收，不能用电脑尺寸模拟代替。
