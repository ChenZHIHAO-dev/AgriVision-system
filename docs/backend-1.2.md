## 功能与数据流

用户可以只发文字。作物缺失时返回小麦、玉米、花生选择卡；生育期缺失时按作物显示选择卡，也允许“先不填写”。用户已明确的信息保存在当前咨询中，不重复补问。

从聊天框添加图片后，先确认作物、生育期和选填品种，再由独立 CNN 处理。DeepSeek 只收到识别状态、候选类别、模型版本、作物与生育期等文字；不会收到图片内容、图片地址或多模态请求字段。原本输入的提问随图片识别结果继续发送。

本轮小麦采用 EfficientNet-B0，详见[模型说明](model-card-wheat-v1.md)。识别状态区分需要模型、需要补拍、不确定、已取得初步结果和服务错误；实验模型有单独标识。玉米与花生仍保留入口和知识资料，未伪造识别结果。

## DeepSeek 接入

模型提供 `deepseek-flash` 与 `deepseek-v4-pro`；两者均支持显式开启 / 关闭 thinking。调用使用服务端 `/chat/completions`，思考开启时设置 `reasoning_effort=high`。当前为非流式回答，等待期间显示发送状态。

已按[官方首次调用文档](https://api-docs.deepseek.com/zh-cn/)和[思考模式文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)核对参数，并通过实际本机 API 验证四种模型 / 思考组合。

系统提示词要求用自然中文回答农业咨询，结合真实识别状态给出观察建议；没有图像、天气或当前虫情工具时不声称已查看或查询。每轮最多追问两个关键问题。资料和历史中的指令被作为用户数据处理，不改写系统规则。

公司产品库尚未录入。用量、配方、混配等问题进入既有产品标签核对规则；不通过自由生成的剂量冒充审核方案。调用失败、余额不足、认证失败和限流有统一提示，可回退到本地资料。

### 密钥

位置：`F:\college\AgriVision\secrets\deepseek.env`。

```dotenv
DEEPSEEK_API_KEY="在本机填写"
```

用户已填写时保持原文件。开发代理没有读取该文件；后端运行时用 python-dotenv 加载，支持引号，关闭变量插值。整个 secrets 目录被 Git 忽略。前端只取得“是否配置”的布尔值，API 和日志不返回密钥；测试使用独立临时假密钥。

环境变量中的非空 `DEEPSEEK_API_KEY` 优先于该文件。配置 URL 和默认模型可使用根目录 .env；不要把密钥放进 `VITE_*`。

## 资料文件

支持 TXT、MD、含可复制文字的 PDF、DOCX；单文件不超过 8MB，同次咨询不超过 6 份，PDF 不超过 80 页。支持 UTF-8 / GB18030 文本；DOCX 保留段落并合并同段落的文字片段。扫描 PDF、加密 PDF 返回明确提示。

原始文件在本机解析，最多保留 30,000 字正文；根据问题分段检索，最多四个摘录送入对话。接口只返回附件名称、字数、截断状态等元数据，文件正文不会随记录列表回传。疑似包含访问密钥的文件被拒绝。

目前是 JSON 知识条目和文档关键词检索，没有向量数据库、OCR 或联网资料工具。前端体验模式不解析正文，明确显示“连接后端后可解析正文”。

## 接口

沿用 `X-Client-ID` 本机会话标识；记录与附件需归属当前会话。当前不是服务端账户认证。

| 接口 | 输入与行为 |
| --- | --- |
| GET /api/meta | 返回模型就绪情况、对话模型列表、资料类型、密钥配置布尔值 |
| POST /api/consultations | 创建纯文字咨询，crop 可为空，stage / location 可填 |
| POST /api/cases | multipart 图片、crop、stage、location、note；创建并识别 |
| POST /api/cases/{id}/context | 补充 crop、stage、variety、location、note |
| POST /api/cases/{id}/images | multipart 图片，可附 crop / stage / variety；识别并记录版本 |
| POST /api/cases/{id}/attachments | multipart file 与可选 filename；本机提取资料文字 |
| DELETE /api/cases/{id}/attachments/{attachment_id} | 移除当前咨询拥有的资料 |
| POST /api/cases/{id}/messages | text ≤ 12,000 字，model、thinking、attachment_ids、image_ids；返回回答及可选 follow_up |
| GET /api/cases/{id} | 返回状态、附件元数据、消息和识别版本 |

附件 ID 必须属于该次咨询；非法模型名、外来附件、超过限制和并发修改都有校验。已有 SQLite 继续保存本机业务记录，本轮没有新增用户账户数据库。

## UI 调整与测试

网页使用 Vue 渲染的原生 textarea，避免 uni-app 自动高度包装导致多行文本超出最大高度。输入区根据可视窗口限制高度，长文本在框内滚动。Shift + Enter 换行，Enter 发送；输入法组词阶段拦截回车发送；接近字数限制时提示。

底部有添加照片 / 资料菜单、原生模型下拉、深度思考开关和发送按钮。补问用选择卡，照片参数确认用对话框。灰黑主题采用独立语义色：背景 #101114、面板 #191a1e、正文 #f4f4f5、次级文字 #c0c3cb，补齐原生输入和选项颜色。

12 项前端测试覆盖状态和输入行为，含本地 DOM 下的长文本、换行与输入法回归。模拟 DOM 的高度测试不能替代真实浏览器排版。本轮浏览器控制不可用，尚未完成 1.2 浏览器视觉和手机软键盘复核。
