# 1.3 手机交互与平台适配清单

更新：2026-11-18。客户端版本：1.3.0-dev.1。当前已完成本地与线上发布验证。本轮只调整前端；沿用现有识别模型、后端接口和基本信息收集流程。

## 一、页面与入口

主页面仍为「首页｜拍照｜我的」三等分，拍照位于正中。文字咨询与拍照并行，但不再增加第四个底部标签。

- 首页：拍照问诊、文字咨询两个明确入口；下方为最近问诊 / 参考资料。
- 拍照：先选择作物，再拍摄或上传；可直接进入文字咨询，也可恢复本次识别。
- 结果：作为拍照页上层窗口展示，关闭返回原拍照页。继续对话沿用当前照片和识别摘要。
- 聊天：独立沉浸界面，明确返回目标；底部主导航隐藏，历史在左侧。识别详情仍是聊天上层窗口。
- 我的：账户、退出登录、使用偏好；手机顶栏在此保留外观循环切换。
- 参考资料：位于首页栏目，搜索、类别筛选和网格 / 列表工具在向下阅读时保持可达。

不拍照也可先提问。作物、生育期等基础资料由程序收集，未发送实际问题时不调用 DeepSeek；补齐资料后恢复原问题的已有逻辑保持不变。

## 二、手机顶栏规则

“动态”优先指当前内容和工具发生变化，核心导航始终可用。不能用整个顶栏定时消失来实现。

| 状态 | 核心导航 | 次级工具 |
| --- | --- | --- |
| 初次进入 / 页面顶端 | 保留标题、历史或返回、登录 / 头像 | 完整显示，停留多久都不自动收起 |
| 前 80px 浅滚动 | 保留 | 完整显示，避免轻微滑动就闪烁 |
| 深入阅读，滚动位置增加 | 保留 | 根据实际滚动距离逐步上移，最多 46px |
| 向页面顶端方向回看 | 保留 | 随滚动距离逐步展开 |
| 深度位置停止超过 1.2 秒 | 保留 | 仅收起临时展开的次级工具，220ms 过渡 |
| 回到顶端 | 保留 | 恢复完整工具，并持续显示 |
| 聊天 / 设置 / 资料页 | 使用页面专属标题和返回 | 聊天不叠加通用快捷工具；资料使用自己的吸顶控件 |

工作台提供参考资料、文字咨询、拍照；滚动到记录区域后标题切为最近问诊。拍照页提供文字咨询。我的提供设置。资料页保留“返回工作台”，自己的搜索和筛选直接吸顶。标题切换仅使用短暂淡入位移，不改变导航行高度。

拖动过程跟随滚动距离，不反复启动缓动；停止后收尾才使用过渡。减少动态效果偏好开启时关闭相关动画。核心导航行 54px，额外系统安全区单独计算。

## 三、网页、小程序和 APP 分工

| 平台 | 当前实现 | 验证边界 |
| --- | --- | --- |
| 桌面 H5，宽度 > 760px | 保留左侧主导航、历史侧栏与桌面顶栏；不运行手机顶栏视觉动画 | 1280×800 浏览器检查通过 |
| 手机 / 窄屏 H5，宽度 ≤ 760px | 手机核心顶栏 + 页面工具 + 底部三项导航；通过 VisualViewport 处理键盘遮挡 | 390×844、390×650；390×480 模拟键盘检查通过 |
| 微信小程序 | 条件编译使用原生键盘事件；自定义顶栏位于状态栏和胶囊区域下方，胶囊底部额外留 6px | 小程序构建通过；微信开发者工具和真机待验收 |
| APP | 保留状态栏 / 键盘高度适配入口，避免与 H5 的 DOM 监听重复生效 | 尚未打包或真机验收 |

H5 的窄屏预览只验证响应式布局，不能代表微信胶囊、原生键盘或相机权限已经验收。将顶栏放在微信胶囊下方是本版保守策略，后续真机可进一步压缩顶部空间。

## 四、底部导航与输入

- 普通点击立即切换页面；重复点击当前拍照入口不清空识别结果。
- 长按 280ms 出现稍大的半透明玻璃滑块；拖动只预览目标，松手才切换一次。
- 手势取消、移出导航区域和普通滚动不切页；释放后的合成 click 不重复触发。
- 长按释放后玻璃滑块淡出，选中状态由图标颜色、柔和底色和短横线持续表达。
- 鼠标、触屏分别接入；键盘 Enter / Space 激活，方向键 / Home / End 移动焦点。
- 聊天空输入保持一行 24px；提示语换行不撑高空框。内容增加时最多八行 192px，超出在框内滚动。
- 手机输入 Enter 换行；桌面 Enter 发送、Shift + Enter 换行；中文输入法组合阶段不误发送。
- 联网检索说明保持静态，仅右侧开关可切换，动画只在开关滑块中。Pro 的不可用原因仍明确说明。
- 手机不展示桌面快捷键和技术说明等辅助文字，空输入时整个输入区约 84px。

## 五、键盘与视觉规范

键盘出现时保留应用画布和核心顶栏尺寸，只移动聊天输入区或当前登录窗口；对话内容预留键盘遮挡空间，不把整个软件压扁。登录窗口受可见高度限制并可内部滚动。H5 使用可视视口；小程序使用原生高度事件，并关闭输入组件默认页面上推，避免重复补偿。

继续沿用微灰浅色和中性灰黑深色。常用图标线宽由 1.8 调至 2.2，深浅资源分别生成，避免错误反色。返回、登录等操作有柔和底色；分隔线保持轻量。手机外观入口只保留在“我的”顶栏和设置中，桌面仍在登录 / 头像旁保留。

## 八、参考依据

下面资料用于理解平台规范，80px / 46px / 1.2秒是本项目交互参数，不是平台强制值。

- [Apple HIG：Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：标题帮助用户定位，按上下文提供常用操作，收起工具应能可靠恢复。这里采用“核心导航常驻、工具按上下文变化”的设计。
- [MDN：VisualViewport](https://developer.mozilla.org/en-US/docs/Web/API/VisualViewport)：区分布局视口和可视视口，并通过 resize / scroll 获取可见范围，供 H5 输入位置适配。
- [uni-app：胶囊边界](https://uniapp.dcloud.net.cn/api/ui/menuButton.html)：小程序单独获取胶囊矩形，避免把手机网页的顶栏坐标直接照搬。
- [uni-app：textarea](https://uniapp.dcloud.net.cn/component/textarea.html)：原生输入的键盘高度、行数变化和默认上推行为按平台分别处理。
