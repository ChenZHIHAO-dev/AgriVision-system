数据目录已按 `wheat / maize / peanut / crop-identification` 分开，原图与工作图按用途保存，不按实验复制。水印、跨标签冲突、既有增强但缺母图关系的来源暂缓；具体数量以[数据说明](data-sources.md)为准。每次可用改动先测试、提交和推送，再发布；实验成绩、曲线与指令只更新[训练清单](recognition-training-checklist.md)，不新建多份计划。

交叉验证用于估计方法表现和选型，本身不会把一个模型自动训练得更强。每折都是一次独立训练；选出方案后再训练部署模型。把多个折模型集成另属推理方案，会增加 CPU 内存和耗时，本轮不默认部署五个模型。

不为每轮实验新建图片集。在线增强只在训练读取时执行；少数类可通过损失权重或有上限的采样调节，不能把增强图数当作独立田间样本数。先使用轻增强，按固定折比较加强方案，不同时叠加强采样与强逆频率损失。

[分组分层交叉验证官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.StratifiedGroupKFold.html) · [真实场景差异的原始研究](https://arxiv.org/abs/1604.03169)

## 两阶段图像识别

作物识别使用整株或有辨识度的图像，输出候选供用户确认。已知作物时直接拍异常部位。病害识别按确认的作物选择权重。小麦先处理已有叶片和麦穗资料。地区与生育期可用于检索、补问以及独立评估。现有图像特征不足时提示需要补拍或区分的部位。

分类模型包放在 `artifacts/models/crop-identification` 或 `artifacts/models/<作物>`，各自携带同一次实验的 `weights.pt` 和 `metadata.json`。通过同一套训练、校准、评估和 API 概况接入。实验完整包保留在原实验目录用于复现，服务统一从 `artifacts/models/<作物>` 加载通过检查的部署副本，每任务只保留一个上一版回退位置。模型类别由模型包管理，资料卡独立补齐。新增模型先在固定留出数据、本地 API 和目标 CPU 上验证，再补充独立田间验证。 [CPU 接入步骤](recognition-training-checklist.md#8-接入本地-api-与后续部署)

## 资料与问答

1. 将农业部门、农技机构公开资料、专业书籍与论文按来源入库。记录章节或页码、DOI 或原文、发布时间、地区和审核状态。扫描资料先提取文字并核对。`data/knowledge` 里的课件和文本用于提取线索与溯源。 [中国农业科学院病虫参考书](https://ipp.caas.cn/kxyj/kycc/zz/74046.htm) · [全国农技中心小麦防控资料](https://www.agri.cn/sc/zxjc/zwbch/202604/t20260428_8832031.htm)
2. 将长期病害资料和年度防控通知按病害、地区与生育期检索。用药依据单独维护有效登记号、作物、防治对象、标签用法和复核日期，再按适用条件返回可查证内容。 [农业农村部农药登记查询指引](https://zzys.moa.gov.cn/gzjl/202401/t20240130_6446755.htm)
3. 以现有关键词检索为基线。资料扩充后用相同问题比较中文全文和混合检索，记录用到的资料 ID 与版本。先覆盖主要病类、上下文不全、易混病例、资料过期和证据不足。 [SQLite FTS5](https://www.sqlite.org/fts5.html)
4. 在相同证据与评测题下对比模型。持续收集允许使用且已去标识的失败样例，再根据结果决定是否微调。更新防治和登记等可变资料时维护来源与生效日期。

对外联网试测按 [微信与服务端接入步骤](wechat-deployment.md) 执行。先在 CPU 云机测实际延迟和并发，后续按用量和存储情况扩容。真实账户与资料管理在有内测反馈后单独迭代。

## 对外开放前的登记与数据保护（2026-11-27 核对）

当前用户确认：个人开发、单管理员测试，不向用户收费，登录用于身份核验和防滥用；网站 ICP 已完成，公安备案及 AI 应用登记待办，运营主体展示名称和联系邮箱待定。以上是实际状态，不能显示为已完成全部备案或合规认证。参考资料与官方农业资讯可供游客浏览，识别、问答、个人记录仍需身份。

网站备案不代替 AI 应用登记。国家网信办 2026-11-20 公告说明，直接调用已备案模型能力的应用/功能由地方网信办开展登记，并要求公示所用模型名称及备案号或上线编号。应按实际服务范围向属地部门核实办理；不虚构号码。分类识别网络不生成照片，DeepSeek 生成的问答文本另按生成式服务管理。单管理员封闭研发与向公众开放的适用条件不同，不能把“有登录”当成豁免依据。 [最新登记公告](https://www.cac.gov.cn/2026-11/20/c_1796918603542950.htm) · [暂行办法原文](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)
