# AgriVision 开发测试版 1.0 需求与验收

本版本面向南阳农资企业的开发与内部体验，在本机浏览器及微信小程序编译端验证拍照问诊流程。产品名称为 AgriVision 宛农植保助手，版本号为 1.0.0-dev.1。

## 用户与任务

农户选择小麦、玉米或花生，上传症状照片并补充种植情况；门店人员查看记录、查询知识资料和产品标签依据。一个问诊保存照片、识别版本、种植信息和对话。

## 功能范围与验收

| 编号 | 功能 | 验收条件 |
| --- | --- | --- |
| F01 | 网页与微信小程序共用前端 | 网页构建与微信小程序构建均通过，界面按屏宽重新排布 |
| F02 | 作物与地区 | 三种作物平铺选择；南阳及部分周边地区级联选择，其他地点可手填；生育期随作物变化 |
| F03 | 图片问诊 | 拍照或相册入口，网页支持拖入；接收 JPG、PNG、WebP，单张上限 8MB |
| F04 | 图片校验 | 解析实际图片内容；过小、极暗极亮和明显细节不足时提示补拍，不伪造候选 |
| F05 | 模型接入 | 按作物读取真实模型包；权重、标签与验证状态齐全才可推理，否则返回待模型状态 |
| F06 | 演示流程 | 用户主动打开标注清楚的演示记录，完整体验结果、资料与咨询；演示不处理用户照片 |
| F07 | 问诊与补图 | 每次问诊保存地区、生育期、备注，最多 6 张图片，补图保留识别版本 |
| F08 | 连续咨询 | 对话绑定当前问诊；有密钥时使用 DeepSeek，未配置或服务失败时返回本地资料说明并标明来源 |
| F09 | 植保知识检索 | 内置 15 条资料卡，按作物和中文关键词检索，展示资料来源与时间 |
| F10 | 用药资料规则 | 具体配方与剂量问题进入结构化规则；只展示经维护审核的适用产品，初始产品目录为空 |
| F11 | 历史与删除 | 当前本地会话最多显示最近 100 条，支持筛选、搜索、打开和删除；删除清除关联图片与对话 |
| F12 | 运行状态 | 显示本地服务、各作物模型、对话配置及资料数量；支持修改后端服务地址 |
| F13 | 数据处理框架 | 生成可复现清单，合并重复与近重复来源组；冲突标签隔离；组内图片不跨训练与评测集合 |
| F14 | 模型训练与评测 | EfficientNet-B0 和 MobileNetV3-Small，共用标签与预处理，导出权重、指标和元数据 |
| F15 | 本机启动 | 提供安装、启动、停止脚本及本地 API 文档；后端可同时服务已构建的网页 |

## 模型与数据边界

本轮交付模型框架与可运行的演示功能，病害数据尚未批量下载，正式病害权重尚未训练。真实图片会如实显示模型准备状态，演示图片采用项目自制植物示意图。

合成图像仅用于训练链路检查，不用于证明病害识别效果，不激活为业务模型。真实模型需检查独立测试、实拍覆盖、易混类别与拒识表现，再进入接入流程。

## 用药与知识边界

内置资料以观察、补拍和资料入口为主。公司具体产品、完整标签、适用作物与对象、剂型含量、有效期和农技维护信息尚需提供。产品目录为空时仍可完成资料咨询，但不生成具体用量与混配比例。

知识检索当前使用按作物过滤和中文词片匹配，已提供检索增强问答入口；语义向量索引、资料管理后台和大规模文档导入后续增加。

## 开发环境与发布区别

当前是本机单用户开发服务，浏览器用本地会话标识区分记录；此标识用于开发数据隔离，不等同于账号认证。正式开放外网前需接入登录、用户权限、HTTPS、配额与备份。微信小程序真机与发布还需实际 AppID、可访问的后端地址和平台配置。

本版不包含社区、交易支付、专家排班、实时天气和手机离线模型。后续按用户试用和真实数据评测安排。
